# Specs

Each non-trivial feature gets a spec file here, created during the RPI Research phase and updated when the plan is approved.

Specs record the **what and why** — not implementation details (those live in the code and git history).

## Format

```
specs/
  feature-slug.md   # one file per feature/epic
```

See `.claude/commands/rpi-research.md` for the spec template.
